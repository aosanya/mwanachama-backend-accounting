### Why this repo exists

Mwanachama's only monetary object, `contribution`, is a mirror of an
outside paybill statement — it has never been a ledger the organization
owns. The merchandise domain already proved that a real double-entry
ledger works well in this platform (`internal/domain/merchandise`, ported
2026-08-24 under DEV-1306), but its invariant is held-stock, not zero-sum
currency, so it was not generalized — this is a new, purpose-built general
ledger instead, arrived at through a dev-research session on 2026-09-03
(recorded as [DSN-1698](../../../developer/documentation/2.%20design/todo.md)).

**Decision: new repo, same architecture as `taskmanager`.** A Go package
on `mwanachama-backend-shared`'s Postgres entity-graph store, imported
directly by `mwanachama-backend-api-gateway`. No gRPC, no sub-service
shape, no Supabase, no RLS.
